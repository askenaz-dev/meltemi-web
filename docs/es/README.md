# Cuenta y servicios de Meltemi

[English](../README.md)

Usa estas guías para iniciar sesión en Meltemi, gestionar tu cuenta y utilizar el espacio de
administración cuando tengas un rol administrativo. Puedes leer y buscar en la documentación sin
iniciar sesión.

## Tu cuenta

- [Iniciar sesión y gestionar tu cuenta](account.md): GitHub o Google, inicios de sesión
  vinculados, dispositivos, perfil, preferencias y eliminación de cuenta.
- [Usar la administración](administration.md): roles, invitaciones, permisos de cuentas,
  publicaciones y el control de IA de documentación para quienes tienen acceso.

## Elige un producto

| Quieres…                                                                       | Empieza aquí                                                              |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Crear, editar o exportar diagramas                                             | [Meltemi Diagrams](https://docs.meltemi.dev/es/diagrams/getting-started/) |
| Trabajar con agentes de programación en una app local de escritorio o terminal | [Meltemi IDE](https://docs.meltemi.dev/es/ide/quickstart/)                |
| Guardar proyectos de Diagrams en tu cuenta y trabajar con otras personas       | [Diagrams en el navegador](https://docs.meltemi.dev/es/diagrams/web-app/) |

Meltemi IDE y la creación local de diagramas funcionan sin cuenta Meltemi. La cuenta añade
proyectos alojados de Diagrams y colaboración; no hace falta para empezar a dibujar localmente.

## Encuentra ayuda

Usa **Buscar** para encontrar una guía. **Preguntar** puede responder una pregunta sobre la
documentación con enlaces a sus fuentes cuando las respuestas de IA están disponibles; revisa
esas fuentes antes de confiar en la respuesta. La búsqueda de páginas y las guías siguen
disponibles cuando las respuestas de IA están pausadas o no están disponibles.

En la portada de documentación, ambos controles usan todos los productos. Dentro de las guías
de un producto, empiezan con ese producto. Usa el selector de producto de cualquiera de los
diálogos para elegir otro producto o **Toda la documentación**; cambiar el alcance conserva tu
pregunta.

El [sitio de Meltemi](https://meltemi.dev/es/) presenta los productos. El
[aviso de privacidad](https://meltemi.dev/es/privacy/) y los [términos](https://meltemi.dev/es/terms/)
explican los servicios alojados.
