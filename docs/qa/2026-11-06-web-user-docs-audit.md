# Web user documentation audit — 2026-11-06

Source baseline: Meltemi Web `f2b1af3`. This audit covers every Web page that the portal previously
published and all six replacement user pages. The portal's publication policy, search and the
family-wide checks belong to the parent change `user-guides-and-product-search`.

## Publication decisions

| Source                                      | Finding                                                                                                                                                                         | Resolution                                                                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Repository `README.md` as Web overview      | Describes packages, development and infrastructure rather than helping a product user.                                                                                          | Add `docs/README.md` and `docs/es/README.md` as the section's real user overview. The repository readme remains a contributor entry point. |
| `docs/repositories.md`                      | Contains local machine paths, repositories, Terraform, secrets names, transport contracts, rollout history and stale implementation status. It has no Spanish user counterpart. | Keep the internal repository map intact and exclude it from the public portal in `audience.ts` (parent implementation).                    |
| `docs/documentation-ai.md` and Spanish copy | Owner operations mixed with build caches, API status schemas, allowance/billing configuration and infrastructure-specific diagnostics.                                          | Keep the operator record intact and exclude it from the portal. Public owner instructions move to the administration user guide.           |
| `docs/administration.md` and Spanish copy   | Mixed personal settings, implementation details (`ADMIN_SUBS`, Origin, CSRF, same-origin private navigation) and old console section labels.                                    | Rewrite as role-based console tasks with current labels and routes; link to the separate account guide.                                    |
| New `docs/account.md` and Spanish copy      | Account tasks were scattered across UI implementation and the administration guide.                                                                                             | Document sign-in, provider linking, active sessions, profile/preferences, sign-out and deletion in one ordinary-user guide.                |

No original internal record was deleted or rewritten. The six public pages have real English and
Spanish content with matching heading structure, tasks, links and limitations.
