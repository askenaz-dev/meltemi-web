# Meltemi account and services

[Español](es/README.md)

Use these guides to sign in to Meltemi, manage your account and use the administration workspace
when you have an administrative role. You can read and search the documentation without signing
in.

## Your account

- [Sign in and manage your account](account.md): GitHub or Google, linked sign-ins, devices,
  profile, preferences and account deletion.
- [Use administration](administration.md): roles, invitations, account permissions, publications
  and the documentation AI control for people with access.

## Choose a product

| You want to…                                                      | Start here                                                             |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Create, edit or export diagrams                                   | [Meltemi Diagrams](https://docs.meltemi.dev/diagrams/getting-started/) |
| Work with coding agents in a local desktop or terminal app        | [Meltemi IDE](https://docs.meltemi.dev/ide/quickstart/)                |
| Save Diagrams projects in your account and work with other people | [Diagrams in the browser](https://docs.meltemi.dev/diagrams/web-app/)  |

Meltemi IDE and local diagramming work without a Meltemi account. An account adds hosted
Diagrams projects and collaboration; it is not required to start drawing locally.

## Find help

Use **Search** to find a guide. **Ask** can answer a documentation question with links to its
sources when AI answers are available; check those sources before relying on the answer. Page
search and the guides remain available when AI answers are paused or unavailable.

On the documentation home, both controls use all products. Inside a product's guides, they start
with that product. Use the product selector in either dialog to choose another product or
**All documentation**; changing the scope keeps your question.

The [Meltemi site](https://meltemi.dev/) introduces the products. The
[privacy notice](https://meltemi.dev/privacy/) and [terms](https://meltemi.dev/terms/) explain the
hosted services.
