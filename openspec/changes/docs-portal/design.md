# Design

## Context

The site is hand-written HTML under `packages/site/public/`, built by `scripts/build.ts`
(esbuild for the module scripts, the sea's stills), served as the assets of a Worker with no code
(`wrangler.jsonc` with `assets`, `_headers` with a strict Content-Security-Policy), checked by
`test/site.test.ts` over the files and by `scripts/browser.ts` in the runner's Chrome. The
identity Worker is the model of a Worker with code: `src/worker.ts` with handlers that are plain
functions of `(request, env, deps)`, tests in Node with stubs. Terraform (`packages/infra`,
provider `cloudflare ~> 5.28`) declares every Worker in `local.workers` with its Custom Domain,
the deploy tokens' permission groups per repository in `tokens.tf`, and the products'
repositories' environments and secrets in `github.tf`, among them the IDE's `WEB_DISPATCH_TOKEN`
from `var.web_dispatch_token`; `tests/stages.tftest.hcl` checks the plan without credentials.
`deploy.yml` deploys only CI-approved current main, under the `production-reconciliation` queue,
identity then the site; `scripts/ide-release.mjs` asks GitHub for the IDE's latest release at
deploy time and tolerates no answer. The IDE's `release.yml` has a `tell the web` job that runs
`gh workflow run deploy.yml --repo askenaz-dev/meltemi-web`; the Diagrams one has none.

Meltemi Diagrams' `docs/` is sixty Markdown guides with a Spanish mirror in `docs/es/` of the
same file names, a `README.md` index per language that links the guides in a curated order, a
`[Español](es/…)` twin link on each page's first line, relative links to each other and to files
outside `docs/` (`../CONTRIBUTING.md`, `../CHANGELOG.md`, `../gallery/README.md`), `docs/media/`
(a GIF and an MP4), and `text` fences holding `.meltemi` sources. The IDE's `docs/` is forty
Spanish guides with `media/` and subfolders, no index. This repository's docs are
`docs/repositories.md` and `docs/decisions/`. Starlight (`@astrojs/starlight` 0.42, MIT, on
Astro 7) reads `src/content/docs/` through `docsLoader()`, requires a `title` in every page's
frontmatter and takes the page heading from it, serves a root locale and `/es/` from `locales`,
shows the default language with a notice where a translation is missing, bundles Pagefind and
lets `components.Search` and `components.Footer` be overridden. Workers AI is a binding
(`"ai": { "binding": "AI" }`) with 10,000 neurons a day free on the Workers Free plan (decision
0003), also callable from the build through `POST /accounts/{id}/ai/run/{model}` with a token
that reads Workers AI; the rate-limiting binding (`ratelimits`, `simple: { limit, period }`,
period 10 or 60 s) is configuration, not a resource; Vectorize is created with `wrangler`, not
declared in Terraform. Workers on the Free plan have 10 ms of CPU per request. See proposal.md
for the motivation.

## Goals / Non-Goals

**Goals:**

- One build, `pnpm --filter @meltemi/docs build`, that turns the three repositories' Markdown
  into the portal, in three modes: `release` (GitHub, at deploy), `local` (the sibling checkouts
  under `C:\meltemi`), `fixture` (`test/fixtures/`, the one `pnpm test` and CI use).
- Everything declared in Terraform stays declared there; what Terraform cannot declare is
  configuration in `wrangler.jsonc` or a file in the assets, never a resource made by hand.
- A question costs one embedding and one answer, under the Worker's CPU limit, and nothing of it
  is kept.

**Non-Goals:**

- A version switcher: the portal shows each product's latest release, named on the page.
- Rendering MDX, Mermaid or raw HTML the product docs do not use today.
- Streaming answers; a conversation (every question stands alone).

## Decisions

1. **Starlight on Astro, the content generated.** `packages/docs` is a Starlight site whose
   `src/content/docs/` is written by the build (gitignored) from the fetched sources, since
   `docsLoader()` reads that folder and documents no other. `astro.config.mjs`: `site:
   "https://docs.meltemi.dev"`, `locales: { root: { label: "English", lang: "en" }, es: { label:
   "Español", lang: "es" } }`, the sidebar autogenerated per section (`diagrams`, `ide`, `web`),
   `pagefind: true`, `lastUpdated: false`, `credits: false`, the image service set to Astro's
   passthrough so no native dependency is needed, `components.Search` and `components.Footer`
   overridden. Alternatives: a hand-written static generator over `marked` (every feature of a
   docs site to write: sidebar, search, locales, theme toggle); Docusaurus (React, heavier;
   MDX-first); VitePress (Vue; its i18n routes the same way, but Starlight's Pagefind and
   fallback notices come built in and Astro's integrations fit a Worker's assets as is).

2. **Sources are release archives, read by this repository's tar reader.** `scripts/sources.ts`
   resolves each product's tag through `GET /repos/{repo}/releases/latest` (the IDE's script
   already does; `main` when GitHub answers 404 because no release exists yet), downloads
   `https://codeload.github.com/{repo}/tar.gz/{ref}`, inflates it with `node:zlib` and reads the
   ustar entries under `docs/`, `README.md`, `README.es.md`, `CONTRIBUTING.md`, `CHANGELOG.md`
   (the files the docs link) with a reader of about eighty lines (`scripts/tar.ts`, tested on an
   archive written by the test), writing `sources.json` `{ product: { repo, ref, version, date }
   }` that the Footer reads. `local` mode reads `../../../diagrams`, `../../../ide` and this
   repository; `fixture` mode reads `test/fixtures/{diagrams,ide,web}`, a dozen pages that
   exercise every rule below. This repository's section always comes from the checkout being
   built. Alternatives: GitHub's contents API (one request per file, rate limited); git
   submodules (a commit per release, the thing the IDE notice avoids); a `tar` package (ISC, one
   more dependency for a fixed, simple format).

3. **Conversion rules, one function per rule.** `scripts/convert.ts` turns a source page into a
   content page: the first `# Heading` becomes `title` and is removed; the first paragraph,
   plain, becomes `description`; a first-line `[Español](…)` or `[English](…)` link to the twin
   is dropped (Starlight has the language picker); links to `.md` files inside `docs/` become
   portal routes (`README.md` → the section's index; `docs/es/x.md` → `/es/<section>/x/`;
   anchors kept), links to files outside `docs/` become `https://github.com/{repo}/blob/{ref}/…`,
   links to `media/` become `/<section>/media/…` with the file copied; `editUrl` is
   `https://github.com/{repo}/blob/{ref}/docs/…`; `sidebar.order` is the page's position in the
   section's index (`docs/README.md` by language, else the repository's README), pages the index
   does not link sorted after it by path; a page that exists in one language only is also written
   to the other locale with the same title, a one-sentence notice in that locale's language
   ("This guide exists in Spanish only" / "Esta guía sólo existe en inglés") and a link, so both
   sidebars are complete and Starlight's own fallback is never shown. Every rule has a fixture
   page and a test.

4. **Pictures from `text` fences.** `scripts/pictures.ts` takes every `text` fence of a page,
   writes it to a temporary file and runs `meltemi-diagrams export <file> --stdout --fonts
   system` (the `@meltemi/diagrams-cli` devDependency, pinned; it needs no browser for SVG); a
   fence that exports with no error becomes the fence followed by `<figure>` with the SVG inline
   (its text set in the portal's Inter, declared once in the portal's CSS) and an `alt` from the
   page's title; a fence that fails stays a fence (the diagnostics guide's deliberate errors).
   One export per fence, cached by the fence's hash in `.cache/` so a rebuild draws only new
   fences. Alternative: a `meltemi` fence tag the product docs would have to adopt (a change of
   their files; detection by exporting needs none).

5. **The Worker: assets plus one route.** `src/worker.ts` serves `env.ASSETS` for everything but
   `POST /api/ask`, and `src/ask.ts` is `ask(request, env, deps)` with `deps = { embed, answer,
   limit, index }` so tests run in Node with a fake embedder (a deterministic hash of the text
   into a vector), a fake model and a fake limiter. `wrangler.jsonc`: `assets` with `binding:
   "ASSETS"`, `"ai": { "binding": "AI" }`, `ratelimits: [{ name: "ASK_LIMIT", namespace_id:
   "1", simple: { limit: 10, period: 60 } }]`, `workers_dev: false`, observability as the
   others. The route takes JSON `{ question, lang }` (1 to 500 characters, `en` or `es`), answers
   `400` with a reason for anything else, `429` when the address is over its limit, `503` with
   `reason: "allowance"` when Workers AI refuses (the day's neurons spent) and `{ answer,
   sources: [{ n, title, url, lang }] }` otherwise. It never logs the question; `console` is not
   called with it.

6. **The index is a file in the assets, searched in the Worker.** `scripts/index.ts` splits every
   content page into passages (a heading and its paragraphs, at most 1,500 characters, overlapping
   by one paragraph), embeds them with `@cf/baai/bge-m3` (multilingual, 1,024 dimensions)
   through Cloudflare's API in batches of fifty, and writes `public/ask/index.bin`: a JSON header
   (passages: section, title, url, lang, the passage's first 300 characters) and, per passage, a
   128-byte sign-bit vector and a 1,024-byte int8 vector. The Worker fetches it once per isolate,
   ranks every passage by Hamming distance on the sign bits (32 words per vector, under a
   millisecond for ten thousand passages), rescores the best fifty by int8 dot product and keeps
   the top eight, well inside the Free plan's 10 ms of CPU. The build without a token writes a
   header with no passages, so the route answers `503 allowance` and the page still builds
   offline; the fixture tests use the fake embedder. Alternatives: Vectorize (a resource
   `wrangler` creates and Terraform cannot declare, a second service per question); AI Search
   (managed indexing of an R2 bucket, created in the dashboard, its citations undocumented);
   float32 brute force (12 MB and over the CPU limit).

7. **The answer.** `deps.answer` runs `@cf/zai-org/glm-4.7-flash` (instruction following in a
   hundred languages, the cheapest text model of the catalogue on 2026-11-04; the id is one
   constant, `ASK_MODEL`, with `@cf/qwen/qwen3-30b-a3b-fp8` noted beside it) with a system prompt
   that says to answer in the question's language from the numbered passages only, to cite them
   as `[n]`, and to say "The documentation does not cover this" when they do not; `max_tokens`
   400. The dialog renders the answer as text paragraphs (never HTML) with `[n]` turned into
   links to the sources list. A question costs about 25 neurons, so a day's free allowance is
   about four hundred answers; `ASK_DAILY_NOTICE` in the messages says the rest.

8. **The portal's own words and looks.** `src/messages/{en,es}.ts` typed as the identity
   service's: the Ask dialog (button, placeholder, "Sources", the allowance and error sentences),
   the untranslated notice, the Footer's "From Meltemi Diagrams v1.11.0 · Source on GitHub".
   `src/styles/tokens.css` is the site's `tokens.css` copied by `pnpm site:tokens` (the 41 family
   tokens, checked equal by the same test), mapped to Starlight's `--sl-color-*` custom
   properties; the lockup from `packages/site/public/media/`; motion: the dialog opens over
   `--motion` with the family's easing, Pagefind's modal as Starlight ships it, and nothing moves
   under `prefers-reduced-motion`.

9. **Headers and policy.** `public/_headers` gives every page `Content-Security-Policy:
   default-src 'none'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline';
   img-src 'self' data:; font-src 'self'; connect-src 'self'; base-uri 'none'; form-action
   'none'; frame-ancestors 'none'` (Pagefind runs WebAssembly from `'self'`, Starlight's theme
   script and inline styles are externalised or hashed through Astro's CSP support, which the
   task verifies on the installed version and the browser check enforces), the same
   `Referrer-Policy`, `X-Content-Type-Options`, `Permissions-Policy` and
   `Strict-Transport-Security` as the site, `Cache-Control` of a day for `/_astro/*` (hashed) and
   five minutes for pages and `index.bin`. No cookie, no analytics, no external request:
   the site test's "no external resource" check runs over `dist/`.

10. **Terraform and the pipeline.** `local.workers` gains `docs = { name = "meltemi-docs",
    repository = "meltemi-web", hostname = "docs.meltemi.dev", zone = "dev" }`; `attached`
    excludes it until `var.docs_deployed` is true (a Custom Domain needs a version, as
    `site_on_apex` staged the apex): the first apply declares the Worker, the first deploy
    uploads it, the next apply attaches the domain. `deploy_groups.web` gains "Workers AI Read"
    (the build's embeddings; the precondition names a missing group). `github.tf` gains
    `github_actions_secret` `WEB_DISPATCH_TOKEN` for the Diagrams repository from
    `var.web_dispatch_token`, present when the owner has it. `deploy.yml` gains the job `docs`
    after `deploy`, same source and queue: `pnpm --filter @meltemi/docs build --from release`
    with `GH_TOKEN`, `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`, then `wrangler deploy`
    in `packages/docs`; a product whose archive cannot be read fails the job and leaves the
    portal as it was, the site's deploy untouched. Diagrams' `release.yml` gains `tell the web`
    as the IDE's, on `WEB_DISPATCH_TOKEN`.

11. **Checks.** `packages/docs/test/`: `tar.test.ts`, `convert.test.ts` (one case per rule),
    `pictures.test.ts` (the fixture's three fences: one draws, one is a fragment that fails, one
    is prose), `index.test.ts` (passages, the binary layout, the fake embedder), `ask.test.ts`
    (input, limit, allowance, sources, no logging), `portal.test.ts` over a `fixture` build in a
    temporary folder (every page has a title and both locales, the sidebar order, the headers,
    no external resource, the Pagefind bundle present, `sources.json` named on pages), and
    `browser.ts` like the site's (search finds a fixture word, the Ask dialog with `/api/ask`
    answered by `wrangler dev` and a `.dev.vars` stub mode, light and dark, reduced motion).
    `test/workflows.test.ts` gains the `docs` job's rules; `stages.tftest.hcl` the fifth Worker
    and the staged domain. Nothing reaches the network.

12. **The decision note.** `docs/decisions/0007-documentation-portal.md`: the portal in this
    repository, sources at the releases, the generated content, pictures from fences, the index
    in the assets with Workers AI, what stays out and why.

## Risks / Trade-offs

- [Astro's CSP support does not cover a Starlight inline script] → the browser check runs with
  the policy enforced and fails on a violation; the fallback is `script-src` with the hashes the
  build computes from `dist/`, written into `_headers` by the build.
- [A product's Markdown uses something the converter does not expect] → the conversion fails
  naming the page and the construct; `local` mode shows it before a release does.
- [The free allowance runs out] → `503 allowance`, the dialog's sentence, the search still works;
  the daily reset is Cloudflare's.
- [The embedding model changes its dimensions] → the index header records model and dimensions;
  the Worker refuses an index whose model is not its own constant and answers `503`.
- [The Worker's CPU on the Free plan] → the binary prefilter; `ask.test.ts` times the ranking of
  ten thousand fake passages under 5 ms in Node.
- [GitHub's tarball of Diagrams is large] → the reader streams and keeps `docs/` and five files
  only; the job's time is minutes, not the site's.
- [Two locales from one language for the IDE] → the notice pages say so; nothing is machine
  translated.
