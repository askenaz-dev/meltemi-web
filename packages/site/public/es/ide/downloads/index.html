Descargas

Todos los enlaces de abajo apuntan a la última release publicada. En esta página no aparece ninguna versión y aquí no se hospeda nada: los archivos vienen de la propia release, así que lo que descargas es lo que se publicó y se atestiguó.

Elige tu plataforma

Plataforma Núcleo (daemon + terminal) Cliente de escritorio
Windows 10 1809+ / 11 meltemi-Windows.zip meltemi-desktop-Windows.msi
macOS 13+ meltemi-macOS.tar.gz meltemi-desktop-macOS.dmg
Linux (Debian/Ubuntu) meltemi-Linux.tar.gz meltemi-desktop-Linux.deb

El archivo del núcleo trae ambos binarios: el daemon meltemid y el cliente de terminal meltemi. Ningún instalador de escritorio empaqueta un navegador: cada uno usa la vista web de tu propio sistema operativo — arrancada en Windows, ya presente en macOS, declarada como dependencia del paquete en Linux. Por eso no hay AppImage: ese formato es autocontenido por construcción, así que tendría que llevar el motor dentro, unos 79 MB de motor.

Fuera de la familia Debian todavía no hay instalador de escritorio. El cliente de terminal y el daemon corren en cualquier distribución desde el archivo del núcleo, y la app de escritorio se compila desde el código. Un .rpm es el siguiente paso.

O usa el script instalador

Los scripts son cortos y están hechos para leerse antes de ejecutarse. Cada uno se publica como artefacto de la release con su checksum dentro del SHA256SUMS que cubre la atestación de la release, y cada uno verifica el checksum del archivo y rehúsa si no coincide. Aquí no hay tubería ciega a una shell: descárgalo, léelo y entonces ejecútalo.

macOS y Linux

curl -fsSLO https://github.com/askenaz-dev/meltemi/releases/latest/download/install.sh
less install.sh
sh install.sh

install.sh

Windows

irm -OutFile install.ps1 https://github.com/askenaz-dev/meltemi/releases/latest/download/install.ps1
notepad install.ps1
./install.ps1

install.ps1

Ambos colocan meltemi y meltemid en tu PATH y crean el alias corto mel. ¿Prefieres hacerlo a mano? El equivalente manual está escrito al inicio de cada script.

Verifica lo que descargaste

Cada release publica un SHA256SUMS y la firma la atestación que acuña su propio workflow de release al publicarla: no la firma ninguna persona ni ninguna clave de largo plazo. Dos comprobaciones, ordenadas por lo que cada una compra: el checksum te dice que el archivo llegó intacto, y la atestación de qué repositorio, commit y workflow salió ese mismo archivo. 

sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify meltemi-Linux.tar.gz --repo askenaz-dev/meltemi --signer-workflow askenaz-dev/meltemi/.github/workflows/release.yml

Cada release trae también attestation.sigstore.json, el bundle con el que la segunda comprobación funciona sin red. Los comandos de cada plataforma, la comprobación sin red y qué puede y qué no puede probar cada comprobación están en la documentación de release.
