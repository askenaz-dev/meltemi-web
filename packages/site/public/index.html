Meltemi: two open-source tools, one family

One steers coding agents. The other draws diagrams as code.

Meltemi IDE is a control plane for the coding agents you already use. Meltemi Diagrams turns text files into diagrams you can adjust on a canvas and export. They are separate programs, released separately: you can use one without the other.

Two products

Meltemi IDE

Apache-2.0 Windows, macOS, Linux Before 1.0

The spec-driven control plane for agentic development. It orchestrates the coding agents you already use, through open standards, under a discipline where no line of code is written without a reviewed specification.

A desktop application and a terminal application. No accounts, no cloud service, no telemetry: you bring your own agent, key and model.

Open the IDE page

Meltemi Diagrams

MIT Command line, VS Code, browser No account needed

Diagrams written as code. You write .meltemi text files and the editor draws them beside the code. Every move, resize or label change on the canvas becomes a small edit of the same text, so a diagram is reviewed and versioned like the rest of your work.

Flow, sequence, C4 and free compositions, exported to SVG, PNG, PDF, an offline HTML player, MP4, WebM and GIF. The app in the browser works without an account.

What the two share

One brand

Both carry the Meltemi mark and name, and Diagrams exports carry the family mark by default. This site wears the design tokens of the IDE's desktop client.

Open source

Meltemi IDE is Apache-2.0. Meltemi Diagrams is MIT. The IDE's source is on GitHub.

One optional account

The family's online services will share a single account. You sign in with GitHub or Google, and there are no passwords. Meltemi IDE never asks for one, and Meltemi Diagrams works without one. What the account holds is written on the privacy page.

Honest state of each product

▲ Different stages. Meltemi IDE is before 1.0: the contract between its daemon and its clients may still change between minor versions. Meltemi Diagrams is built and tested without an account; the account, sharing and collaboration that are meant to sit on top of it do not exist yet.
